What the DFT Does

The DFT converts sampled signal values x[j] into frequency-domain coefficients X[k] so we can see which oscillations are present in the signal.

Why Naive DFT Is Slow

Each output X[k] multiplies every input x[j] by a root of unity, so n outputs each require n interactions, giving n^2 total pairings.

How FFT Speeds It Up

FFT splits the transform into even and odd subproblems, reuses smaller DFTs, and combines them with twiddle factors in only log2(n) stages.

What Butterfly Circuits Mean

A butterfly represents one structured combine step: two values enter, one twiddle factor is applied, and two transformed outputs leave.

Teaching Notes

Algorithm Overview, Worked Example, and Presentation Support

Overview

The Discrete Fourier Transform takes a finite list of samples and expresses it as a combination of discrete frequency components. It is useful in signal processing, filtering, compression, spectral analysis, communications, and polynomial multiplication.

Naive DFT

The naive DFT can be written as matrix-vector multiplication: X = W x. The matrix W contains powers of the primitive n-th root of unity, so each output X[k] is a weighted sum of every input sample.

Roots of Unity

For size n, the root of unity is omega = e-2pi i/n. Powers of omega lie on the complex unit circle and rotate by equal phase increments. The DFT reuses these rotations to measure how strongly each frequency pattern matches the signal.

Even/Odd Split

Cooley-Tukey FFT separates the input into even-indexed and odd-indexed samples. That converts one large transform into two smaller transforms that can be reused and combined instead of recomputed from scratch.

Butterfly Operation

A butterfly combine step computes a = even + twiddle * odd and b = even - twiddle * odd. This pair of additions and one multiplication is the atomic building block of the FFT circuit.

Bit Reversal

The iterative FFT processes butterflies stage by stage. Bit-reversed input order makes each stage operate on the correct subproblems without recursive function calls, so the circuit layout lines up with the mathematical decomposition.

Complexity

Naive DFT uses n outputs and n terms per output, so it scales like O(n^2). FFT has log2(n) stages with n/2 butterflies per stage, so its structure scales like O(n log n). For n = 8, that is about 64 pair interactions versus 12 butterflies.

Worked Example: n = 4, x = [1, 0, 1, 0]

The naive DFT gives X = [2, 0, 2, 0]. FFT splits the signal into even samples [1, 1] and odd samples [0, 0], computes two smaller transforms, then combines them with twiddle factors. Both algorithms produce the same final output.

Presentation Checklist
  • First I show the input signal.
  • Then I compute the naive DFT.
  • Next I compare it with FFT.
  • The key structural advantage is the even/odd split.
  • The butterfly network shows the O(n log n) structure.
  • Finally, I verify that FFT output matches the naive DFT output.
